# Furrow

Autonomous coding agent with an infinite parallel development loop.

## Commands
- `furrow start "<goal>"` — run a development cycle
- `furrow web` — start the web UI

## Agents
- `furrow` — primary orchestrator
- `furrow-planner` — decomposes goals into parallel tasks
- `furrow-worker` — executes individual tasks
- `furrow-tester` — runs tests and reports results
